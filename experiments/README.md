# Experiments and benchmark runs

Keep small, shareable, non-sensitive inputs and reproducible summaries here when a real project exists. Store large logs, model checkpoints, videos and secrets outside Git (`artifacts/`, `outputs/` are gitignored). Each experiment should state hypothesis, code commit, exact command, environment, baseline, same case IDs/seeds, full denominator, result and failures; an experiment's GitHub issue/PR may contain the record instead of duplicate Markdown. Never label synthetic fixture metrics as real results.
